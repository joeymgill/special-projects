<h1>Rankings & Awards Component</h1>
<p>A responsive, accessibility-conscious card component adapted from a production CMS component I designed and developed for a university website.
The original implementation integrates with Modern Campus CMS and an XSLT publishing workflow. This repository is a CMS-independent demonstration using static sample content and generic visual branding.</p>
<hr>
<h2>Features</h2>
<ul><li>Responsive three-column desktop and two-column tablet layouts</li>
<li>Centered incomplete grid rows</li>
<li>Touch-friendly single-card mobile carousel</li>
<li>Previous and next navigation with disabled boundary states</li>
<li>Programmatically associated carousel instructions</li>
<li>Live-region slide announcements</li>
<li>Text, icon, and image visual treatments</li>
<li>Keyboard-visible focus states</li>
<li>Reduced-motion support</li>
<li>Progressive enhancement</li>
<li>Reusable BEM-style CSS architecture</li></ul>
